# GMod_GUI

> GMod 开发工具箱 | Fluent Design 风格桌面工具
> 基于 Rust + Tauri

## 📖 简介

**GMod_GUI** 是面向 Garry's Mod 开发者的桌面工具箱，采用 Fluent Design 深色卡片 UI，用于简化 GMod 模组开发流程：GMA 打包/解包、创意工坊上传、多语言配置、资源管理等。

> 本仓库为**发行版下载/发布页**，仅提供编译好的可运行包，不包含源代码。

## 📦 下载安装

从本仓库的 **Releases / 发行版** 页面下载最新 `GMod_GUI.zip`：

| 平台 | 安装包 | 说明 |
| ---- | ------ | ---- |
| Windows | `GMod_GUI-win64.zip` | 解压后运行 `GMod_GUI.exe` |

**安装步骤：**
1. 下载 `GMod_GUI-win64.zip`
2. 解压到任意目录（建议放在非系统盘，如 `K:\GMod_GUI`）
3. 双击运行 `GMod_GUI.exe`，无需额外安装
4. 首次运行在设置中指定你的 GMod 项目目录即可

## ✨ 功能特性

- ✅ GMA 文件：打包、解包、预览
- ✅ 创意工坊：GMA 快速上传，配置管理
- ✅ 多语言界面（可扩展）
- ✅ Fluent Design 深色主题卡片布局
- ✅ Source 模型 QC/SMD 辅助信息查看
- ✅ 项目路径管理，快速打开本地 GMod 项目目录

## 🖥️ 使用说明

1. 启动程序
2. 导入资源文件夹，一键打包为 `.gma`
3. 填写工坊配置，直接上传到 Garry's Mod 创意工坊
4. 查看/编辑多语言文本，适配 Lua 模组语言文件

## ⚠️ 注意事项

- 本工具**仅用于个人/自制模组开发**，请遵守 Steam 创意工坊协议
- 不提供破解、绕过创意工坊校验功能
- Source 模型编译（QC/SMD）仅做信息读取，编译本体仍依赖 Source SDK
- 若被杀毒软件误报，请添加信任（工具基于 Rust + Tauri 开发，未加壳）
- 配置文件与日志存放于程序目录下，重装时注意备份 `config` 文件夹
